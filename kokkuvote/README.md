# Kokkuvõte

## Põhimõisted
- **Git** - versioonihaldus, mis jälgib muudatusi
- **Commit** - salvestatud muudatus
- **Push** - muudatuste saatmine GitHubi
- **Branch** - eraldi tööharu
- **Pull Request** - muudatuste ühendamise ettepanek

## Mida õppisin
Git aitab tööd korrastada ja muudatusi jälgida.  
Commit salvestab lokaalselt, push saadab GitHubi.  
Harud võimaldavad katsetada ilma main‑haru rikkumata.  
Pull Request aitab muudatused enne ühendamist üle vaadata.  
Git on parem kui USB‑ga kopeerimine, sest kõik jääb ajalukku.

## Näide
Kui teen uue funktsiooni eraldi branch’is ja midagi läheb katki, ei mõjuta see `main` haru.
