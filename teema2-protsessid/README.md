# Teema 2: Protsessid

## Põhimõisted
| Mõiste | Selgitus |
|--------|----------|
| **Protsess** | Korduv tegevuste jada kindla tulemuse saavutamiseks |
| **Standard** | Kokkulepitud viis töö tegemiseks |
| **Töövoog** | Sammud, mille kaudu info liigub |
| **Ressurss** | Vahend, mida on vaja tööks |
| **Efektiivsus** | Kui hästi protsess töötab |

## Mida õppisin
Protsessid muudavad töö ühtlasemaks ja kiiremaks.  
Kui kõik järgivad sama süsteemi, on vähem vigu.  
Protsess ei pea olema keeruline - peaasi, et see on loogiline.  
Hea protsess säästab aega ja vähendab segadust.
