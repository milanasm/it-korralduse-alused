# Teema 4: Lean

## Põhimõisted
- **Lean** - mõtteviis, mis keskendub raiskamise vähendamisele
- **Raiskamine** - tegevus, mis ei lisa väärtust
- **Väärtus** - see, mis on kliendi jaoks oluline
- **Optimeerimine** - protsessi paremaks muutmine
- **Jätkuv parendamine** - pidev areng väikeste sammudega

## Mida õppisin
Lean aitab mõelda, kuidas tööd lihtsamaks teha.  
Raiskamine võib olla aeg, liigne töö või ootamine.  
Oluline on keskenduda sellele, mis loob väärtust.  
Lean sobib hästi ka IT‑valdkonda.

## Näide
Kui tööriistad on laiali ja otsin neid kaua, on see raiskamine.
