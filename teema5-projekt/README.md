# Teema 5: Projekt

## Põhimõisted
| Mõiste | Selgitus |
|--------|----------|
| **Projekt** | Ajutine töö kindla eesmärgi ja tähtajaga |
| **Projektijuht** | Inimene, kes juhib projekti |
| **Eelarve** | Projekti jaoks ette nähtud raha |
| **Risk** | Asi, mis võib projekti segada |
| **Tulemus** | Projekti lõplik saavutus |

## Mida õppisin
Projekt vajab selget plaani ja eesmärki.  
Riskid tuleb ette näha, mitte oodata probleemi.  
Hea suhtlus on projektis väga oluline.  
Projekt lõpeb alles siis, kui tulemus on üle antud.

## Näide
Uue arvutiklassi ehitamine: seadmete valik, eelarve, paigaldus, testimine, üleandmine.
